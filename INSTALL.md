Pour installer Odoo

- Suivre la video
  https://youtu.be/wWnZu7-63jU?si=gr1sctRIOrJJ4ld9
- Creation d'un environnement spécifique (soit venv, soit conda)
- Fork le repo de Odoo
- Clone le repo
- Utilisation de VScode, de Miniconda,
- Télécharger Buildtools.exe
- Télécharger la base PostgreSQL
- Télécharger wkhtmltox.exe

- Bien garder les username et password --> credentials.yml

- Puis voir dans README.md
